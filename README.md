# Data-Science-Related-Projects
These are all the data science related projects I have. 


If you look in the Linear Regression Analysis folder, there's 2 projects: 
1. The Python version of my Linear Regression and Data Analysis of the Sleep Health and Lifestyle data from Kaggle
2. A linear regression analysis on Diamond Data to find correlations between all qualitative metrics of a diamond.

1. StoPredProj.ipynb uses a trained PyTorch model to predict the TSLA Stock Price
2. PredictionProject 1.ipynb uses TensorFlow to predict the TSLA Stock Price

If you look in the Time Series Forecasting folder, you can see the time series forecasting I did for the US WHO Suicide Statistics.
